# Beauty Hut Africa · The Skin Edit

A runway-style landing page for Beauty Hut Africa. Six hero products stand in a line that recedes into the distance. Dragging, scrolling or the arrow keys bring the next edit to the front, while the product rail scrolls in sync.

- Single self-contained `index.html` (HTML, CSS and vanilla JS, no build step)
- Fonts: Poppins (Google Fonts)
- Product imagery is embedded as two WebP sprite sheets

Open `index.html` in a browser, or view the live site via GitHub Pages.
